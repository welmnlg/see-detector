# YouTube Hide Suggestions Extension

This Chrome extension hides video suggestions on YouTube to provide a cleaner, distraction-free viewing experience.

## Features
- Hides video suggestions on the YouTube homepage and video pages
- Simple and lightweight
- Easy to use: just install and enjoy

## Installation
1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable "Developer mode" (top right).
4. Click "Load unpacked" and select this extension's folder.

## Usage
Once installed, the extension will automatically hide YouTube suggestions. No further action is required.

## Files
- `manifest.json`: Extension manifest file
- `content_script.js`: Script that hides suggestions
- `popup.html`: Popup UI (if any)
- `popup.js`: Logic for the popup
