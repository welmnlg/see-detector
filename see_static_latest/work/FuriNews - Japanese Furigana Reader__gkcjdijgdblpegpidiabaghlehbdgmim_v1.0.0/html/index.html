Japanese Furigana Reader - 漢字にふりがなを自動表示

ニュース記事の漢字が読めるようになる

日本語のニュースサイトで記事を閲覧する際、漢字の上にふりがな（読み仮名）を自動的に表示します。日本語学習者のための便利なツールです。

日本語にほんごの新聞しんぶんを読よむのが楽たのしくなる！

Chrome に追加 Edge に追加

主な機能

📖

自動ふりがな表示

記事の漢字に自動的にふりがなを表示します

🎨

品詞カラー表示

名詞・動詞・形容詞など品詞ごとに色分け表示

🔒

完全オフライン

すべての処理はローカルで完結。データ送信なし

簡単操作

ワンクリックでオン/オフ切り替え

For Japanese Learners

Struggling to read kanji in Japanese news articles? This extension automatically displays furigana (reading guides) above kanji characters, making it easier to read and learn Japanese.

🔒 Privacy First

All text processing happens locally on your device using the bundled kuromoji.js library. No data is ever sent to external servers.
