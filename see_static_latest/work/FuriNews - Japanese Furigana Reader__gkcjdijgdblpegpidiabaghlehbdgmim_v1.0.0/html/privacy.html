Overview

"FuriNews" is a browser extension that adds furigana (reading guides) to Japanese text on news websites. This extension is designed for Japanese language learners.

Key Point: We do not collect, store, or transmit any personal data. All processing happens locally on your device.

Data Collection

We do not collect any data. Specifically:

  • No user data is collected: We do not collect names, emails, or any personal information.
  • No browsing history is tracked: We do not track which pages you visit.
  • No data is sent to external servers: All text processing is done locally on your device.
  • No analytics or tracking: We do not use any analytics services.

How the Extension Works

  1. The extension reads text content from Japanese news article pages.
  2. All Japanese text analysis (tokenization) is performed locally using the kuromoji.js library bundled with the extension.
  3. Furigana annotations are added directly to the page DOM.
  4. Your settings are stored locally in Chrome's storage API and never transmitted.

Permissions Explained

Permission Purpose
activeTab Required to access and modify the current page content to add furigana.
storage Required to save your preferences (on/off state, color mode) locally.

Third-Party Services

This extension does not use any third-party services, APIs, or analytics.

Data Storage

The only data stored is your local preferences:

  • Whether the extension is enabled for specific pages
  • Color mode setting (on/off)

This data is stored locally using Chrome's storage.local API and is never transmitted.

Changes to This Policy

If we make changes to this privacy policy, we will update the "Last updated" date at the top of this page.

Contact

If you have questions about this privacy policy, please create an issue on our GitHub repository.

概要

「FuriNews」は、日本語ニュースサイトの漢字にふりがな（読み仮名）を自動的に付けるブラウザ拡張機能です。日本語学習者向けに設計されています。

重要: 本拡張機能は、個人データを一切収集、保存、送信しません。すべての処理はお使いのデバイス上でローカルに行われます。

データ収集について

データは一切収集しません。 具体的には：

  • ユーザーデータの収集なし：名前、メールアドレス、その他の個人情報を収集しません。
  • 閲覧履歴の追跡なし：どのページを訪問したかを追跡しません。
  • 外部サーバーへのデータ送信なし：すべてのテキスト処理はお使いのデバイス上でローカルに行われます。
  • 分析やトラッキングなし：分析サービスを使用していません。

拡張機能の動作

  1. 拡張機能は日本語ニュース記事ページのテキストコンテンツを読み取ります。
  2. すべての日本語テキスト分析（形態素解析）は、拡張機能に同梱されているkuromoji.jsライブラリを使用してローカルで実行されます。
  3. ふりがな注釈はページのDOMに直接追加されます。
  4. 設定はChromeのストレージAPIを使用してローカルに保存され、送信されることはありません。

権限の説明

権限 目的
activeTab ふりがなを追加するために現在のページコンテンツにアクセスして変更するために必要です。
storage 設定（オン/オフ状態、カラーモード）をローカルに保存するために必要です。

サードパーティサービス

本拡張機能は、サードパーティのサービス、API、分析ツールを使用していません。

データの保存

保存されるデータはローカル設定のみです：

  • 特定のページで拡張機能が有効かどうか
  • カラーモード設定（オン/オフ）

このデータはChromeのstorage.local APIを使用してローカルに保存され、送信されることはありません。

ポリシーの変更

このプライバシーポリシーに変更を加える場合は、ページ上部の「最終更新日」を更新します。
