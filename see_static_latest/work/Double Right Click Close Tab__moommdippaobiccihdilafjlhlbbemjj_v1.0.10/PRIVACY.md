# Privacy Policy - Double Right Click Close Tab

**Last updated: May 17, 2026**

## Overview

Double Right Click Close Tab is a browser extension that allows users to close a tab by double right-clicking on the page.

## Data Collection

This extension does **NOT** collect, store, transmit, or share any user data whatsoever.

## Local Storage

Double Right Click Close Tab uses Chrome's `storage.local` API to store your right-click menu behavior preference locally on your device. No other data is persisted.

## Permissions and Page Access

- **Content scripts on all URLs**: The extension injects a content script into every web page you visit in order to listen for `mousedown` (right button) and `contextmenu` events. Only the mouse button identifier, event timestamp, and trust flag (`isTrusted`) are read; no page content, URL, cookies, tab title, or other tab metadata is accessed, stored, or transmitted. Synthetic events generated by the page itself (where `isTrusted` is false) are ignored.
- **storage**: Used only to save your right-click menu behavior preference locally.

When the extension detects a genuine double right-click, it sends a single internal message to its own service worker, which calls the standard `chrome.tabs.remove()` API to close the current tab. No tab URL is read in this process.

## Network Requests

This extension makes **zero** network requests. It does not phone home, send telemetry, or communicate with any external server or third-party service.

## Changes

Any changes to this privacy policy will be reflected in extension updates.

If you have questions about this privacy policy, please open an issue on the extension's support page.
