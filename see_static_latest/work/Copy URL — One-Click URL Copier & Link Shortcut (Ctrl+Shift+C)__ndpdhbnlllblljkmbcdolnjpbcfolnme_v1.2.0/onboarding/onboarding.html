!
Custom shortcuts are limited

They won't fire on chrome://, the Web Store, the new-tab page, or PDFs. Ctrl+Shift+C still does.

!
Local files

file:// pages need "Allow access to file URLs" enabled in chrome://extensions.

i
DevTools open?

Ctrl+Shift+C behaves as Chrome's built-in Inspect. Close DevTools to copy URLs instead.
