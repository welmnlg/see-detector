# 📐 Viewport Size — Chrome Extension

> Умный индикатор размеров viewport для адаптивной веб-разработки.

![Chrome](https://img.shields.io/badge/Chrome-Extension-4285F4?style=flat&logo=googlechrome&logoColor=white)
![Manifest](https://img.shields.io/badge/Manifest-V3-green?style=flat)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat)

---

## ✨ Возможности

- 📐 **Ресайз окна** — мгновенно меняй ширину браузера одной кнопкой
- 📏 **Живые размеры** — ширина и высота обновляются в реальном времени при изменении окна
- 🏷️ **Брейкпоинты** — показывает текущий breakpoint (`XS`, `SM`, `MD`, `LG`, `XL`, `2XL`) с цветовой подсветкой и вспышкой при пересечении границы
- 📋 **Копирование по клику** — клик на плашку копирует готовый `@media` запрос в буфер обмена
- 🌗 **Темы** — тёмная и светлая тема оформления
- 📍 **4 позиции** — верхний левый/правый, нижний левый/правый угол
- 💤 **Автоскрытие** — индикатор появляется только при ресайзе и исчезает через 2.5 сек
- 🔢 **Форматирование чисел** — `1 440` вместо `1440`

---

## 🖼️ Как выглядит

```
╭─────────────────────────────────╮
│  ↔ 1 440 px  │  ↕ 900 px  │ XL  │
╰─────────────────────────────────╯
```

При клике на плашку — в буфер копируется:
```css
@media only screen and (max-width: 1440px) {
```

## 🚀 Установка

1. Скачай или клонируй репозиторий
2. Открой **Chrome** → `chrome://extensions/`
3. Включи **Developer mode** (переключатель в правом верхнем углу)
4. Нажми **Load unpacked**
5. Выбери папку с расширением

## ⚙️ Настройки

Кликни на иконку расширения в тулбаре Chrome (ширина попапа 400px):

### 📐 Resize Window
Мгновенно меняет ширину окна браузера — удобно для проверки конкретных брейкпоинтов:

| Кнопка | Ширина |
|--------|--------|
| `600`  | 600px  |
| `768`  | 768px  |
| `820`  | 820px  |
| `1024` | 1024px |
| `Full` | Разворачивает на весь экран |

### Остальные настройки

| Настройка | Описание |
|-----------|----------|
| **Show indicator** | Включить / выключить отображение плашки |
| **Position** | Угол экрана: Top Left · Top Right · Bottom Left · Bottom Right |
| **Breakpoints** | Пресет: Tailwind CSS или Bootstrap |
| **Theme** | Тёмная или светлая тема плашки |

> Настройки сохраняются через `chrome.storage.sync` и синхронизируются между устройствами.

## 🎨 Цвета брейкпоинтов

| Label | Цвет | Tailwind | Bootstrap |
|-------|------|----------|-----------|
| `XS`  | 🩶 Серый    | < 640px  | < 576px   |
| `SM`  | 🔵 Синий    | ≥ 640px  | ≥ 576px   |
| `MD`  | 🟢 Зелёный  | ≥ 768px  | ≥ 768px   |
| `LG`  | 🟡 Жёлтый   | ≥ 1024px | ≥ 992px   |
| `XL`  | 🟣 Фиолет   | ≥ 1280px | ≥ 1200px  |
| `2XL` / `XXL` | 🩷 Розовый | ≥ 1536px | ≥ 1400px |

При пересечении границы брейкпоинта — бейдж кратко вспыхивает и увеличивается.

## 🛠️ Технологии

- **Manifest V3** — современный стандарт Chrome Extensions
- **chrome.storage.sync** — синхронизация настроек между устройствами
- **chrome.windows** — управление размером окна браузера
- **Inline styles** — индикатор не конфликтует со стилями страницы
- **SVG иконки** — чёткие на любом DPI/разрешении
