Link Capture: ページ遷移なしでURLを高速収集！リサーチと情報収集を加速する究極のツール 🚀

短い説明:
Webページ上のリンクを次々にクリックするだけで、ページを移動せずにURLをサイドパネルに収集。リサーチや情報まとめの効率を劇的に向上させます。✨

---

詳細な説明:

情報収集やリサーチ中に「この記事も後で読みたい」「この製品も比較したい」と、たくさんのリンクを一時的に保存したくなることはありませんか？
しかし、タブを開きすぎるとブラウザが重くなり、一つずつURLをコピペするのは面倒です。😩

「Link Capture」は、そんなあなたのためのソリューションです。💡

ツールバーのアイコンをクリックしてサイドパネルを開いたら、あとはWebページ上の気になるリンクをクリックするだけ。ページが遷移することなく、クリックしたURLがリアルタイムでサイドパネルにリストアップされていきます。
これにより、思考を中断されることなく、流れるように情報収集を続けることができます。🚀

集めたURLリストは「すべてコピー」ボタンで一括してクリップボードにコピー可能。
そのままメモ帳に貼り付けたり、話題のAIノート「NotebookLM」などにインプットしたりすることで、収集した情報をシームレスに活用できます。📚

主な機能:
・ ワンクリックURL収集: Webページ上のリンクをクリックするだけで、ページ遷移せずにURLをサイドパネルにストックします。
・ シンプルなサイドパネル: 収集したURLをリアルタイムで確認できます。👀
・ 一括コピー: 収集したURLリストをワンクリックでクリップボードにコピーできます。📋
・ 自動ON/OFF: サイドパネルを開いているときだけURL収集が有効になり、閉じると自動で停止するため、意図しない動作を防ぎます。
・ ダークモード対応: お使いのブラウザ設定に合わせて、目に優しいダークモード表示に切り替わります。🌙

無料版とプレミアム版について:
この拡張機能は、無料でもお使いいただけますが、一部機能に制限があります。

・ 無料版: 収集できるURLの数は3つまでです。🙅‍♀️
・ プレミアム版: URLの収集数が無制限になります。🎉

サイドパネル下部のリンクからライセンスキーをご購入いただき、入力欄から認証することで、いつでもプレミアム版にアップグレードできます。🎁

こんな方におすすめです:
・ リサーチャー、ライター、学生など、大量のWebサイトから情報を収集する方 👨‍🎓👩‍💻
・ 複数の製品やサービスを比較検討している方
・ 後で読みたい記事を一時的にリストアップしておきたい方
・ NotebookLMなどを活用して、効率的に情報整理を行いたい方

注意事項:
・ YouTubeのような動的なウェブサイトでも動作しますが、万が一リンクの収集がうまく機能しない場合は、お手数ですがWebページを再読み込みしてください。🔄
