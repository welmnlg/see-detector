Privacy Policy

Effective date: March 13, 2026

Overview

Teams Transcript Downloader is a browser extension that helps users download video transcript files from Meeting Stream pages. Your privacy is important to us.

Data Collection

This extension does not collect, transmit, or store any personal data on external servers. Specifically:

  • No analytics or tracking scripts are included.
  • No data is sent to any third-party service.
  • No cookies are created or read by the extension.
  • No user accounts or authentication are required.

Data Stored Locally

The extension stores the following data locally on your device only, using the Chrome Storage API:

  • Session data (chrome.storage.session): Temporarily stores transcript URLs detected on the current page. This data is automatically cleared when the browser is closed or the tab is navigated away.
  • Download history (chrome.storage.local): Stores the names and timestamps of recently downloaded transcripts (last 50 entries) for your convenience. This data can be cleared at any time using the "Clear" button in the extension popup.

Permissions Explained

  • storage: Used to save transcript data and download history locally on your device.
  • downloads: Used to trigger the file download when you click the Download button.
  • activeTab: Used to read the current tab's URL to determine if you are on a Meeting Stream page.
  • Host permission (sharepoint.com): Content scripts run only on Meeting Stream pages to detect transcript API responses.

Network Requests

The extension does not make any network requests of its own. It only observes existing network responses on Meeting Stream pages to detect transcript download URLs that SharePoint itself provides.

Third-Party Services

This extension does not integrate with or send data to any third-party services.

Changes to This Policy

If we make changes to this privacy policy, we will update the effective date above and publish the updated policy with the extension.

Contact

If you have questions about this privacy policy, please open an issue on the extension's support page.
