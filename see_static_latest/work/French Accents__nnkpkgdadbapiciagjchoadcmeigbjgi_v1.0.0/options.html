French Accents Settings

Typing Mode

When enabled, a floating overlay keyboard with French accents will appear when you click on any input field. Click any accent button to type it directly into the active field.

How to Use

Overlay Keyboard:

  1. Click on any input field, textarea, or contenteditable element on any webpage
  2. A floating overlay keyboard will appear in the bottom-right corner
  3. Click any accent button to type it directly into the active field
  4. Drag the overlay by its header to reposition it
  5. Click the × button to close the overlay
